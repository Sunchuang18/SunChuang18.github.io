6 类 AI 工作场景应用案例

以下案例均为参会人员实际使用过的真实工作场景，内容具体、可落地、可参考。

01

会议纪要智能生成

WorkBuddy + 豆包

会议结束后，利用 AI 工具自动生成结构化纪要，替代人工整理听写。

▸实际使用场景
通过 豆包 记录会议内容并进行智能总结；同时使用公司提供的 WorkBuddy Skill 按标准模板生成会议纪要，支持直接导出为 HTML 格式，纪要规整度高。
★价值收益
自动梳理核心要点、待推进事项及对应截止时间，省去会后人工整理 1-2 小时的工作量。
02

业务数据对比分析

AI 表格识别 · 数据服务部

针对业务侧提交的多份申诉相关数据表，AI 自动识别表格差异，替代人工逐行核对。

▸实际使用场景
数据服务部涉及 漏裁数据申诉、抽检、AI 识别拍照 等业务，将两份待排查差异的表格上传至 AI，自动比对后统计差异并反馈给对应对接人。
★价值收益
告别逐行人工核对，差异识别准确且快速，显著降低重复劳动强度。
03

SDD 模式开发新需求

SDD · AI 辅助编程

向 AI 输入完整业务需求，AI 自动输出标准化开发清单，可直接基于清单搭建功能模块。

▸实际使用场景
SDD（Spec-Driven Development）模式：先提需求 → AI 输出执行列表 → 按列表开发。适用于新需求开发场景，将需求拆解为可执行的标准化任务。
★价值收益
需求拆解更规范、开发链路更清晰，减少沟通成本与遗漏，与 MCP 协议能力互不冲突可配合使用。
04

MCP 协议辅助改 BUG

MCP 协议 · 数据库直连

使用支持 MCP 协议的 AI 工具直连数据库，无需手写 SQL 即可查询数据、定位 bug。

▸实际使用场景
在 改 BUG 场景 下，AI 通过 MCP 协议直接连接数据库，自动查询相关数据辅助问题定位。Cursor 等工具已支持相关能力，与 SDD 模式可并行使用。
★价值收益
免手动编写 SQL，数据查询与 bug 定位一体化，调试效率大幅提升。
05

批量文件整理与规范格式

QClaw（QQ 龙虾）

针对命名混乱、格式混杂的大量文件，AI 按规则重命名、分类至指定子目录后打包。

▸实际使用场景
使用 QClaw 工具（腾讯收购），将原本混在同一压缩包内、文件名为乱码的 300 余份不同格式客户作业资料，按指定要求统一规范文件名，并按 机构名、人名 等维度分类到 7 个子目录 自动完成规整打包。
★价值收益
原本需人工逐份处理的繁杂归类工作一键完成，准确率与效率同步提升。
06

问道平台项目智能问答

问道 · 公司自研工具

使用公司内部「问道」平台，选定对应项目即可查询产品逻辑、系统报错原因及解决方案。

▸实际使用场景
问道关联 代码库，可针对 指定项目 问答产品逻辑、查询系统 bug 成因及获取解决方法。目前 CBS 相关项目 已纳入，需开通对应项目权限才可使用。
★价值收益
「真的很能节约时间，以前我们都是要找开发去看」—— 大幅减少跨部门咨询开发的时间成本。
CORE VALUE

AI 助力工作的三大核心价值

贯穿 6 类场景的共性优势——这是参会人员反复提及的 AI 核心价值。

⚡

节约时间

从会议纪要到文件整理，从数据比对到 bug 定位，AI 将原本数小时的人工工作压缩至分钟级。"就很能节约时间"成为讨论中反复出现的高频词。

🎯

提升准确率

AI 自动识别表格差异、按规则规范文件命名，避免人工逐行核对与手动操作中的疏漏，准确率与一致性同步提升。

🔗

降低协作成本

问道工具让查询项目逻辑、报错原因不再依赖跨部门咨询开发；SDD 与 MCP 让需求拆解、数据查询一体化，减少沟通环节。

「这我觉得这个真的是很能节约时间，以前我们都是要找开发去看。」
